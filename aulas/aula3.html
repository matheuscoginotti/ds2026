Aula 03: Modelagem Lógica, Chaves PK e FK

Repositório DS 2026 • Professor: Matheus M. Coginotti

Depois de desenhar o Diagrama Entidade-Relacionamento (DER) na Aula 02, o próximo passo é a Modelagem Lógica. É aqui que traduzimos o nosso desenho conceitual para o formato estruturado de tabelas, definindo as regras de identificação e amarração dos dados.

1. Chave Primária (Primary Key - PK)

Em um banco de dados relacional, cada tabela precisa ter uma garantia absoluta de que não existem registros duplicados. Para isso, utilizamos a Chave Primária.

  • O que é? É uma coluna (ou conjunto de colunas) cujos valores identificam de forma única e exclusiva cada linha de uma tabela.
  • Regras: O valor da PK nunca pode ser repetido e nunca pode ser nulo (NOT NULL). Geralmente, usamos um número inteiro sequencial autoincrementável (ex: id_cliente INT AUTO_INCREMENT PRIMARY KEY).

2. Chave Estrangeira (Foreign Key - FK)

Como vimos na aula anterior, as tabelas de um sistema conversam entre si (especialmente nas relações 1 para N). É aqui que entra o conceito de Chave Estrangeira.

  • O que é? É uma coluna em uma tabela (tabela filha) que faz referência direta à Chave Primária de outra tabela (tabela pai).
  • Para que serve? Ela garante a Integridade Referencial. Ou seja, ela impede que você cadastre um produto vinculado a uma categoria que simplesmente não existe no banco de dados.
# EXEMPLO PRÁTICO DE AMARRAÇÃO (1:N)
- Tabela categorias possui a PK: id (1 - Eletrônicos, 2 - Periféricos)
- Tabela produtos possui a FK: categoria_id.
Se tentarmos cadastrar um produto com categoria_id = 99 (sendo que o 99 não existe),
o MySQL bloqueia a transação na hora para proteger a integridade dos dados!
Exercício Prático de Fixação

Considere um sistema de biblioteca com duas entidades: Livro e Editora (onde uma Editora publica vários Livros, mas um livro pertence a apenas uma editora).

  1. Qual será a Chave Primária (PK) da tabela editoras?
  2. Qual coluna deverá ser criada na tabela livros para funcionar como Chave Estrangeira (FK) ligando-a à editora?
