Script SQL Prático: Criando a Loja Simples

Abra o seu navegador, acesse o painel do phpMyAdmin, clique na aba SQL, cole os comandos abaixo e clique em Executar:

-- 1. Criar o Banco de Dados
CREATE DATABASE loja_simples;

-- 2. Selecionar o Banco para uso
USE loja_simples;

-- 3. Criar a tabela de Categorias (Tabela Pai)
CREATE TABLE categorias (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(50) NOT NULL
);

-- 4. Criar a tabela de Produtos (Tabela Filha com FK)
CREATE TABLE produtos (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    preco DECIMAL(10,2) NOT NULL,
    quantidade INT NOT NULL,
    categoria_id INT,
    FOREIGN KEY (categoria_id) REFERENCES categorias(id)
);

-- 5. Inserir dados iniciais
INSERT INTO categorias (nome) VALUES ('Eletrônicos'), (VALUES 'Periféricos');
INSERT INTO produtos (nome, preco, quantidade, categoria_id) VALUES ('Smartphone XYZ', 1500.00, 10, 1);

Lista de Exercícios Práticos para Laboratório

Com o banco criado e rodando no XAMPP, desafie os alunos a resolverem os seguintes exercícios no phpMyAdmin:

Desafio 01: Inserção Avançada

Cadastre 3 novas categorias no banco (ex: Vestuário, Alimentos e Casa). Em seguida, insira 5 produtos diferentes distribuídos entre essas categorias utilizando corretamente a coluna de chave estrangeira (categoria_id).

Desafio 02: Consulta com Filtro (WHERE)

Escreva um comando SELECT que retorne apenas os produtos cujo preço seja maior do que R$ 100,00.

Desafio 03: Atualização de Registros (UPDATE)

Houve reajuste nos preços dos produtos. Escreva um comando UPDATE para alterar o preço de todos os produtos da categoria de ID 2 aplicando um novo valor de sua escolha.

Desafio 04: Remoção Segura (DELETE)

Um produto saiu de linha na loja. Escreva um comando DELETE para remover do banco o registro que possui o ID igual a 2.

Desafio 05: Consulta de Estoque Crítico

O gerente precisa repor o estoque urgentemente. Escreva uma consulta SQL que traga o nome e a quantidade de todos os produtos que estão com menos de 15 unidades disponíveis em estoque.
